Resumo

O Alba é um despertador. Os teus alarmes, sons, fotos e preferências ficam guardados apenas no teu iPhone. O Alba não tem servidores, não pede uma conta e não vende os teus dados. A versão gratuita mostra anúncios da Google, que podem usar alguns dados do teu dispositivo, como se explica abaixo.

Dados que ficam no teu iPhone

  • Alarmes (hora, dias, nome, desafio, som e definições).
  • Sons que importas da app Ficheiros ou de um vídeo.
  • Fotos que escolhes para o ecrã do desafio (é guardada uma cópia reduzida).
  • Objetos que registas para o desafio de leitura de código (nome e código).
  • Preferências: tema, frase, compras e passes ativos.

Mais ninguém tem acesso a estes dados, nem nós. Se apagares a app, são apagados.

Permissões

  • Alarmes: para programar os teus alarmes com o iOS.
  • Câmara: apenas para ler o código que escolheste para o desafio. As imagens não são guardadas nem enviadas.
  • Notificações (opcional): para "Ainda estás acordado?" e para te avisar antes de terminar um passe gratuito.
  • Fotos: usamos o seletor do iOS e só vemos as fotos que escolhes.

Compras

As compras são geridas pela Apple. Não recebemos os teus dados de pagamento.

Anúncios (versão gratuita)

O Alba usa o Google AdMob para mostrar anúncios e a User Messaging Platform (UMP) da Google para pedir o teu consentimento quando a lei o exige (por exemplo, na UE e no Reino Unido).

  • Sem rastreio: o Alba não pede a autorização de rastreio da Apple, por isso os anúncios não usam o identificador de publicidade (IDFA) nem seguem o que fazes noutras apps.
  • A Google pode recolher dados como um identificador do dispositivo para esta app, o teu endereço IP (para estimar uma localização aproximada), informações do dispositivo, interações com anúncios e dados de falhas, para mostrar e medir anúncios e prevenir fraudes.
  • Os anúncios são adequados a todas as idades.
  • Podes alterar o consentimento quando quiseres em Definições > Opções de privacidade dos anúncios.
  • Com o Alba Pro não são mostrados anúncios.

Mais informações: Política de Privacidade da Google (policies.google.com/privacy) e como a Google usa dados das apps dos parceiros (policies.google.com/technologies/partner-sites).

Menores

O Alba não se destina a menores de 13 anos e não recolhemos os seus dados de forma intencional.

Os teus direitos

Como não guardamos os teus dados em servidores, não temos nada para te entregar nem apagar: está tudo no teu iPhone e é removido com a app. Para os dados de anúncios, podes exercer os teus direitos junto da Google e retirar o consentimento nas Definições. Dúvidas: albalarmkit@gmail.com. Também podes apresentar queixa à autoridade de proteção de dados do teu país (em Portugal, a CNPD).

Alterações

Se alterarmos esta política, atualizaremos a data acima e, se a alteração for importante, avisaremos na app.
